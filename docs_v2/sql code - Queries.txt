    -> where interest_name = 'Music Club'

Suppose a student has an interest in Data Analysis, the Music Club, and speaks French. Count the number of students in each major that also match those three interests.

mysql> select major, count(student_id)
    -> from university_student
    -> where student_id in
    -> (
    ->     select student_id
    ->     from student_interest
    ->     where interest_name = 'Data Analysis'
    -> )
    -> and student_id in
    -> (
    ->     select student_id
    ->     from student_interest
    ->     where interest_name = 'Music Club'
    -> )
    -> and student_id in
    -> (
    ->     select student_id
    ->     from student_interest
    ->     where interest_name = 'French'
    -> )
    -> group by major;
+------------------+-------------------+
| major            | count(student_id) |
+------------------+-------------------+
| Physics          |                31 |
| Biology          |                37 |
| History          |                23 |
| Computer Science |                32 |
| Psychology       |                22 |
| Mathematics      |                35 |
+------------------+-------------------+
